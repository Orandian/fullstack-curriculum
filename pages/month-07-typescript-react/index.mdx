# 🟣 Month 7 — TypeScript + React

**Goal:** Add type safety to your React apps with TypeScript.

<Callout type="info">
  TypeScript catches bugs before they happen. Most companies hiring React devs now require TypeScript. Learn it once, use it forever.
</Callout>

## Why TypeScript?

```ts
// JavaScript — no error until runtime
function greet(user) {
  return user.name.toUpperCase(); // crashes if user is undefined
}
greet(); // 💥 TypeError at runtime

// TypeScript — error at compile time
function greet(user: { name: string }) {
  return user.name.toUpperCase();
}
greet(); // 🔴 TS error: Expected 1 argument
```
