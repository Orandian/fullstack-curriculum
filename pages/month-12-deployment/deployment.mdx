# Lesson 1 — Deployment

## Deploy Frontend to Vercel

\### Connect your GitHub repo Go to \[vercel.com\](<https://vercel.com>) → New Project → Import from GitHub

### Configure build settings

```
Framework:        Vite
Build command:    npm run build
Output directory: dist
```

### Set environment variables

```
VITE_API_URL = https://your-backend.onrender.com/api
```

### Deploy

Vercel auto-deploys on every push to `main`. Your frontend is live!

## Deploy Backend to Render

\### Create a Render account Go to \[render.com\](<https://render.com>) → New → Web Service → Connect GitHub

### Configure

```
Runtime:      Node
Build command: npm install
Start command: node src/index.js
```

### Set environment variables

```
NODE_ENV    = production
PORT        = 4000
DATABASE_URL = postgresql://...
JWT_SECRET  = your-super-secret-key
```

### Create PostgreSQL database on Render

New → PostgreSQL → Copy the internal connection string to DATABASE_URL

### Run migrations on deploy

Add to build command: `npm install && npx prisma migrate deploy`

## Environment Variables

```bash
NODE_ENV=development
PORT=4000
DATABASE_URL=postgresql://postgres:password@localhost:5432/myapp
JWT_SECRET=local-dev-secret-change-in-production
FRONTEND_URL=http://localhost:5173
```

```js
// CORS — allow your Vercel frontend
app.use(cors({
  origin: process.env.FRONTEND_URL || 'http://localhost:5173',
  credentials: true,
}));
```

Always add \`.env\` to \`.gitignore\`. Never commit secrets to GitHub. \`\`\`bash echo ".env" &gt;&gt; .gitignore \`\`\`

## Checklist Before Going Live

- \[ \] All environment variables set in production
- \[ \] Database migrations applied
- \[ \] CORS configured for production frontend URL
- \[ \] Error messages don't expose internal details
- \[ \] Passwords are hashed (bcrypt)
- \[ \] JWT secret is long and random (32+ chars)
- \[ \] No `console.log` of sensitive data
- \[ \] README with public URL and setup instructions
