# Project 2 — Login UI (Frontend Only)

**Goal:** Build a complete auth flow — Login, Register, and a protected Dashboard — using React Router, useState, and Context (no real backend).

## Pages

- `/login` — email + password form
- `/register` — name, email, password form
- `/dashboard` — protected page (redirects to /login if not "logged in")
