# 🟠 Month 11 — Fullstack Project

**Goal:** Combine everything learned — React frontend + Node.js/Express backend + PostgreSQL database — into one real, deployable application.

<Callout type="info">
  This month starts with **three lessons** on how to plan and design a fullstack app before writing any code. Skipping this step is why projects fall apart halfway through. The lessons are short — the payoff is large.
</Callout>

## Stack

```
Frontend:  Next.js 14 + TypeScript + Tailwind CSS
Backend:   Node.js + Express + Prisma
Database:  PostgreSQL
Auth:      JWT + bcrypt
Infra:     Docker Compose
Deploy:    Vercel (frontend) + Render (backend)
```

<Callout type="warning">
  **Why Next.js instead of plain React?** Next.js is what you'll use in almost every real job that uses React. It's what this curriculum's docs site runs on. Month 11 is where we bring it in — you have enough React knowledge now that Next.js will feel like React with superpowers, not a completely different thing. See Lesson 4 for the intro.
</Callout>

## This is a Team Project

Work in groups of 2–3 people. Assign roles: frontend, backend, DB/API design. Use GitHub branches and pull requests — not because it's required, but because this is how real teams ship software.

```bash
# One person creates the repo
gh repo create team-blog-app --public
git clone https://github.com/yourteam/team-blog-app

# Use branches for features — never push to main directly
git checkout -b feature/user-auth
git checkout -b feature/post-crud
git checkout -b feature/frontend-auth

# Pull Requests for every feature
gh pr create --title "Add JWT auth" --body "Closes #1"
# Team reviews → approves → merges
```

## Project Requirements (All Options)

- [ ] User registration + login (JWT)
- [ ] Protected routes on both frontend and backend
- [ ] At least 3 database models with relations
- [ ] Full CRUD for the main resource
- [ ] Responsive UI (mobile + desktop with Tailwind)
- [ ] Deployed and accessible via public URL
- [ ] README with setup instructions and screenshots
- [ ] GitHub workflow with feature branches + merged PRs
