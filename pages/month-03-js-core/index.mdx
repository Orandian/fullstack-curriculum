# 🟡 Month 3 — JavaScript Core (Part 1)

**Goal:** Build a deep understanding of the JavaScript concepts every developer uses every single day.

<Callout type="warning">
  This is the month where most students hit a wall. Arrays, objects, closures, and functional methods are genuinely difficult — and they're also used constantly in React, Node, and TypeScript. We give this two full months (3 and 4) because it deserves the time.
</Callout>

<Callout type="info">
  Month 3 focuses on **data structures and functional programming**. Month 4 stays on JS with async operations before moving to React in Month 5.
</Callout>

## Topics This Month

| Lesson | Topic |
|--------|-------|
| 1 | Arrays & Objects — deep dive, destructuring, spread/rest |
| 2 | `map`, `filter`, `reduce` — functional programming basics |
| 3 | Scope, Closures & `this` — the parts JS beginners always skip |
| 4 | Error handling — `try`/`catch`, throwing errors, defensive code |
| 5 | Building Logic with JS — games as a teaching tool |

## Projects

- **Todo App (pure JavaScript)** — full CRUD with localStorage, the state→render pattern
- **JS Logic Games** — build at least two of: Snake, Tetris, Memory Card, 2048. These aren't just fun — they teach loops, arrays, game loops, collision detection, and algorithm thinking in a context where you can immediately see the result.

## Weekly Schedule

<Steps>
  ### Week 1
  Arrays & Objects — creating, reading, mutating (and why you shouldn't mutate), destructuring, spread `[...arr]`, rest `...args`. Practice with lots of small exercises.

  ### Week 2
  Functional methods — `map`, `filter`, `reduce`, `find`, `some`, `every`, `flat`. Understand that these are just loops with better names. No mutation, always returns new data.

  ### Week 3
  Scope & Closures — `var` vs `let` vs `const`, function scope vs block scope, the closure pattern, `this` in different contexts. This is the lesson that makes other JS concepts suddenly click.

  ### Week 4
  Error handling + defensive code — `try`/`catch`/`finally`, custom errors, validating inputs, writing functions that don't explode on bad data. Build the Todo App.

  ### Week 5
  JS Logic Games — build Snake or Tetris from scratch using the Canvas API. Pure JS, no libraries. This is the best way to cement loops, arrays, and state thinking — and the result is something cool you can show people.
</Steps>

<Callout type="info">
  Source code for all four games (Snake, Tetris, Memory Card, 2048) is available in the [curriculum-projects](https://github.com/Orandian/curriculum-projects) repo under `month-03-js-core/games/`. Use these as a reference — not as something to copy before you've tried.
</Callout>
