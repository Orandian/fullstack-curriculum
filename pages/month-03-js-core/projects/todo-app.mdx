# Project — Todo App (Pure JS)

**Goal:** Build a fully functional todo app using only HTML, CSS, and JavaScript — no frameworks.

## Requirements

- [ ] Add todos with a text input
- [ ] Mark todos as complete (toggle)
- [ ] Delete individual todos
- [ ] Filter: All / Active / Completed
- [ ] Show count of remaining todos
- [ ] Clear all completed todos
- [ ] Persist todos in localStorage
- [ ] Keyboard: press Enter to add
