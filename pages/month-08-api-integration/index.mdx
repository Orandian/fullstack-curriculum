# 🟣 Month 8 — API Integration

**Goal:** Connect your React frontend to real APIs using Axios, manage global state with Context, and handle errors gracefully.

## Topics

| Lesson | Topic |
|---|---|
| 1 | Axios & Fetch in React — interceptors, base URL, headers |
| 2 | Error Handling — loading/error/success states |
| 3 | Context API — global state without Redux |

## Projects

- **Dashboard with API** — a data dashboard pulling from a real REST API
- **Auth UI with Mock Backend** — JWT flow with localStorage tokens
