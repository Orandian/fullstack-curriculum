# Project 1 — Personal Profile Page

**Goal:** Build a complete personal profile/portfolio page using HTML and CSS only.

## Requirements

- [ ] Semantic HTML structure (`header`, `main`, `footer`, `section`, `article`)
- [ ] Your name, photo, short bio
- [ ] Skills list with styled badges
- [ ] Work/project section with cards
- [ ] Contact section with links
- [ ] Fully responsive (mobile + desktop)
- [ ] Pushed to GitHub
