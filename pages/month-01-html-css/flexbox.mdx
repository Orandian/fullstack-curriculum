# Lesson 3 — Flexbox

## What is Flexbox?

Flexbox is a CSS layout system for arranging items in **one direction** — either a row or a column. It solves the classic centering and spacing problems that used to require hacks.

## Enabling Flexbox

```css
.container {
  display: flex;
}
```

All direct children become **flex items**.

## Main Axis vs Cross Axis

```
flex-direction: row (default)
─────────────────────────── → main axis
│  item  │  item  │  item  │
─────────────────────────── ↓ cross axis

flex-direction: column
↓ main axis
┌────────┐
│  item  │
│  item  │
│  item  │
└────────┘ → cross axis
```

## Core Properties

### On the Container

```css filename="style.css"
.container {
  display: flex;

  /* Direction */
  flex-direction: row;           /* row | row-reverse | column | column-reverse */

  /* Wrap */
  flex-wrap: wrap;               /* nowrap | wrap | wrap-reverse */

  /* Main axis alignment */
  justify-content: center;
  /* flex-start | flex-end | center | space-between | space-around | space-evenly */

  /* Cross axis alignment */
  align-items: center;
  /* stretch | flex-start | flex-end | center | baseline */

  /* Gap between items */
  gap: 16px;
  gap: 16px 24px;  /* row-gap  column-gap */
}
```

### On the Items

```css filename="style.css"
.item {
  /* Grow to fill available space */
  flex-grow: 1;

  /* Shrink if needed */
  flex-shrink: 0;

  /* Base size */
  flex-basis: 200px;

  /* Shorthand: grow shrink basis */
  flex: 1 0 200px;
  flex: 1;         /* grow=1, shrink=1, basis=0 */

  /* Override container alignment for this item */
  align-self: flex-end;

  /* Order (default 0) */
  order: 2;
}
```

## Common Patterns

### Perfect Centering

```css
.centered {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}
```

### Navigation Bar

```css filename="style.css"
nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 16px 32px;
  background: #1e40af;
}

.nav-logo { font-size: 1.5rem; color: white; font-weight: 700; }
.nav-links { display: flex; gap: 24px; }
.nav-links a { color: white; text-decoration: none; }
```

```html filename="index.html"
<nav>
  <span class="nav-logo">MyBrand</span>
  <div class="nav-links">
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Contact</a>
  </div>
</nav>
```

### Card Grid

```css filename="style.css"
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
}

.card {
  flex: 1 1 280px;   /* grow, shrink, min-width */
  background: white;
  border-radius: 12px;
  padding: 24px;
  border: 1px solid #e5e7eb;
}
```

### Sidebar + Content Layout

```css filename="style.css"
.layout {
  display: flex;
  gap: 32px;
  min-height: 100vh;
}

.sidebar {
  flex: 0 0 240px;   /* fixed 240px, won't grow or shrink */
}

.content {
  flex: 1;           /* take all remaining space */
}
```

<div class="profile-card">

.profile-card {
  display: flex;
  align-items: center;

  padding: 32px;

  height: 96px;
