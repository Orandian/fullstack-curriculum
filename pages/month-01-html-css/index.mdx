# 🟢 Month 1 — HTML + CSS Basics

**Goal:** Build a solid mental model of how websites are structured and styled — the foundation everything else sits on.

<Callout type="info">
  Three focused weeks instead of four. HTML and CSS fundamentals are learnable quickly when you're building something real from day one. By Week 3 you'll have a live profile page. Tailwind CSS and CSS Grid come in Month 2 once you have the fundamentals.
</Callout>

## Topics This Month

| Lesson | Topic |
|--------|-------|
| 1 | HTML Structure — semantic tags, document layout, accessibility basics |
| 2 | CSS Basics + Flexbox — selectors, box model, one-dimensional layouts |
| 3 | Responsive Design — media queries, mobile-first thinking |

## Project

- **Personal Profile Page** — a full webpage with nav, hero, skills section, and contact form. This becomes the foundation of your portfolio.

## Weekly Schedule

<Steps>
  ### Week 1
  HTML Structure — tags, semantic elements (`header`, `main`, `article`, `section`, `footer`), accessibility basics. Build the HTML skeleton of your profile page.

  ### Week 2
  CSS Basics + Flexbox — box model, selectors, specificity, Flexbox layouts. Style your profile page. Finally learn how to center things properly.

  ### Week 3
  Responsive Design — media queries, mobile-first approach, viewport units. Make your profile page look good on a phone. Submit finished project.
</Steps>

<Callout type="warning">
  **CSS Grid** gets its proper treatment in Month 2. You'll see it briefly here but don't worry about mastering it yet.
</Callout>
