# 📋 Program Overview

## Weekly Assignment Pattern

Every single week across all 12 months follows this pattern:

1. **Small task** — practice the concept taught that weekend
2. **Main task** — build a feature of your ongoing project
3. **Bonus task** — for strong students who want to go further

## Evaluation System

| Component | Weight | Description |
|-----------|--------|-------------|
| **Projects** | 50% | Quality of what you build and deploy |
| **Weekly Submissions** | 40% | Consistency across the program |
| **Participation** | 10% | Showing up, asking questions, reviewing others' code |

<Callout type="info">
  Projects carry the most weight because that's what gets you hired. A deployed app on your portfolio is worth more than a perfect homework submission score.
</Callout>

## Rules

**Attendance & Submissions**

- Missing **1–2 submissions**: You'll get a check-in message — everyone has tough weeks.
- Missing **3 or more unexcused submissions**: Formal warning. At 4, we review your place in the program together.
- If something major is happening in your life, **communicate early**. The rule is about silent disappearing, not about being human.

**Code Integrity**

Don't submit code you can't explain. You should be able to walk through every line and describe what it does and why.

Reading documentation, studying patterns from other projects, and using references is completely normal — that's how real developers work. The skill we're building is *understanding*, not memorization. What's not okay is submitting code you don't understand and can't discuss.

**Version Control**

All code must be **pushed to GitHub** with meaningful commit messages. This builds your portfolio and teaches real team habits.

## What Makes This Program Different

- ✅ Real **code review sessions** every month — not just grades, actual feedback
- ✅ **"How to work as a developer"** talk — career advice, professional culture, what hiring managers look for
- ✅ **Resume + portfolio** guidance before graduation
- ✅ Small cohort — you're not anonymous, and your progress is tracked individually

<Callout type="info">
  **Focus:** React + Node.js + real deployed projects. That's the combination that gets junior developers hired. We don't teach everything — we teach what works.
</Callout>
