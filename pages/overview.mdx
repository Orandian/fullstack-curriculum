# 📋 Program Overview

## Weekly Assignment Pattern

Every single week across all 12 months follows this pattern:

1. **Small task** — practice the concept taught that weekend
2. **Main task** — build a feature of your ongoing project
3. **Bonus task** — for strong students who want to go further

## Evaluation System

| Component | Weight | Description |
|---|---|---|
| Weekly submission | 60% | Consistency is everything |
| Projects | 30% | Quality of your builds |
| Participation | 10% | Showing up, asking questions |

<Callout type="warning">
  Keep students accountable. No submission = no progress.
</Callout>

## Rules

- Miss **2 submissions** → removed from program
- **No copy-paste** code — every line must be written by hand
- All code must be **pushed to GitHub**

## Extra (What Makes This Course Special)

- ✅ Real **code review sessions** every month
- ✅ **"How to work in Japan"** talk — career advice and culture
- ✅ **Resume + portfolio** guidance before graduation

<Callout type="info">
  **Focus:** Don't try to teach everything deeply.
  Stick to React + Node + real projects. That's enough to get jobs.
</Callout>
