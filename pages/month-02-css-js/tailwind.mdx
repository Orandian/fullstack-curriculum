# Tailwind CSS

**Why Tailwind?** Most modern React codebases use Tailwind. Learning it now means you won't have to play catch-up when you start Month 5.

<Callout type="info">
  Tailwind is a **utility-first CSS framework** — instead of writing `.card { padding: 1rem; background: white; }` you write `className="p-4 bg-white"`. Same result, much faster once you know the class names.
</Callout>

## Setup

```bash
# In any HTML/JS project:
npm install -D tailwindcss
npx tailwindcss init

# Or use the CDN for quick prototyping:
# <script src="https://cdn.tailwindcss.com"></script>
```

```js
// tailwind.config.js — tell Tailwind where your HTML files are
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ["./**/*.{html,js}"],   // scan these files for class names
  theme: { extend: {} },
  plugins: [],
}
```

## Core Concepts

### Spacing — padding, margin

```html
<!-- Raw CSS equivalent in brackets -->
<div class="p-4">...</div>       <!-- padding: 1rem -->
<div class="px-6 py-2">...</div> <!-- padding: 0 1.5rem + 0 0.5rem -->
<div class="mt-8 mb-4">...</div> <!-- margin-top: 2rem, margin-bottom: 1rem -->
```

Tailwind uses a spacing scale: `1 = 0.25rem`, `2 = 0.5rem`, `4 = 1rem`, `8 = 2rem`, `16 = 4rem`.

### Colors

```html
<div class="bg-blue-500 text-white">Blue card</div>
<div class="bg-gray-900 text-gray-100">Dark card</div>
<p class="text-red-600">Error message</p>
```

Color scale runs from 50 (lightest) to 950 (darkest). `bg-indigo-600` is a very commonly used primary color.

### Flexbox & Grid

```html
<!-- Flexbox: center items horizontally and vertically -->
<div class="flex items-center justify-between gap-4">
  <span>Left</span>
  <span>Right</span>
</div>

<!-- Grid: 3 equal columns -->
<div class="grid grid-cols-3 gap-6">
  <div>Card 1</div>
  <div>Card 2</div>
  <div>Card 3</div>
</div>
```

### Responsive design

```html
<!-- Stacked on mobile, side-by-side on md+ screens -->
<div class="flex flex-col md:flex-row gap-4">
  <div class="w-full md:w-1/2">Left panel</div>
  <div class="w-full md:w-1/2">Right panel</div>
</div>
```

Responsive prefixes: `sm:` (640px+), `md:` (768px+), `lg:` (1024px+), `xl:` (1280px+).

### Hover, focus, dark mode

```html
<button class="bg-indigo-600 hover:bg-indigo-700 focus:ring-2 focus:ring-indigo-400
               text-white font-semibold px-4 py-2 rounded-lg transition-colors">
  Click me
</button>

<div class="bg-white dark:bg-gray-900 text-gray-900 dark:text-white">
  Adapts to dark mode automatically
</div>
```

## Building a Card Component

```html
<div class="bg-white dark:bg-gray-800 rounded-xl shadow-md p-6 max-w-sm">
  <img src="avatar.jpg" alt="User" class="w-16 h-16 rounded-full mb-4 object-cover" />
  <h2 class="text-xl font-bold text-gray-900 dark:text-white mb-1">Jane Doe</h2>
  <p class="text-gray-500 dark:text-gray-400 text-sm mb-4">Fullstack Developer</p>
  <a href="#" class="inline-block bg-indigo-600 hover:bg-indigo-700 text-white
                     text-sm font-medium px-4 py-2 rounded-lg transition-colors">
    View Profile
  </a>
</div>
```

## Exercise

Rebuild your Month 1 profile page using Tailwind instead of raw CSS. Then compare the two versions:

1. How many lines of CSS did you write vs how many Tailwind classes?
2. Which one is easier to change the color scheme on?
3. What happens when you add `dark:` classes?

<Callout type="warning">
  **Common mistake:** Over-using `@apply` to extract Tailwind classes into CSS. Don't. The whole point of Tailwind is to keep styles co-located with your HTML/JSX. Reach for components instead.
</Callout>

## Tailwind in React (Preview)

From Month 5, all your React components will use Tailwind:

```jsx
function Button({ children, variant = 'primary' }) {
  const base = "px-4 py-2 rounded-lg font-medium transition-colors"
  const variants = {
    primary: "bg-indigo-600 hover:bg-indigo-700 text-white",
    ghost: "border border-gray-300 hover:bg-gray-50 text-gray-700",
  }
  return <button className={`${base} ${variants[variant]}`}>{children}</button>
}
```
