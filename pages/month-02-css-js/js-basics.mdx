# Lesson 2 — JavaScript Basics

## What is JavaScript?

JavaScript makes web pages **interactive**. While HTML is structure and CSS is appearance, JavaScript is **behavior** — what happens when users click, type, scroll, or interact.

## Where to Write JS

```html filename="index.html"
<!-- Option 1: Inline (avoid for large code) -->
<button onclick="alert('Hello!')">Click me</button>

<!-- Option 2: Script tag at bottom of body (preferred) -->
<script src="script.js"></script>
```

<Callout type="info">
  Always put your `<script>` tag at the **bottom** of `<body>` so HTML loads first.
</Callout>

## Variables

```js filename="script.js"
// let — can be reassigned
let name = 'Yan Naing';
name = 'YNH';  // OK

// const — cannot be reassigned (use this by default!)
const PI = 3.14;
// PI = 3;  // Error!

// var — old way, avoid it
var old = 'dont use this';
```

## Data Types

```js filename="script.js"
// String
const name = 'Yan Naing';
const greeting = `Hello, ${name}!`;  // template literal

// Number
const age = 25;
const price = 9.99;

// Boolean
const isLoggedIn = true;
const hasError = false;

// Array
const skills = ['HTML', 'CSS', 'JavaScript', 'React'];
skills[0];        // 'HTML'
skills.length;    // 4

// Object
const person = {
  name: 'Yan Naing',
  age: 25,
  skills: ['React', 'Node.js'],
};
person.name;         // 'Yan Naing'
person['age'];       // 25

// Null & Undefined
const empty = null;
let notDeclared;     // undefined
```

## Functions

```js filename="script.js"
// Function declaration
function greet(name) {
  return `Hello, ${name}!`;
}

// Function expression
const greet = function(name) {
  return `Hello, ${name}!`;
};

// Arrow function (modern — use this)
const greet = (name) => {
  return `Hello, ${name}!`;
};

// Arrow function shorthand (single expression)
const greet = (name) => `Hello, ${name}!`;
const double = (n) => n * 2;
const square = n => n * n;  // parentheses optional for single param

// Calling functions
console.log(greet('Yan'));   // Hello, Yan!
console.log(double(5));      // 10
```

## Conditionals

```js filename="script.js"
const score = 75;

// if / else if / else
if (score >= 90) {
  console.log('A');
} else if (score >= 80) {
  console.log('B');
} else if (score >= 70) {
  console.log('C');
} else {
  console.log('F');
}

// Ternary operator (short if/else)
const grade = score >= 70 ? 'Pass' : 'Fail';

// Logical operators
const isAdmin = true;
const isLoggedIn = true;

if (isAdmin && isLoggedIn) { console.log('Full access'); }
if (isAdmin || isLoggedIn) { console.log('Some access'); }
if (!isLoggedIn) { console.log('Please log in'); }
```

## Loops

```js filename="script.js"
// for loop
for (let i = 0; i < 5; i++) {
  console.log(i);  // 0, 1, 2, 3, 4
}

// for...of (for arrays — use this most often)
const skills = ['HTML', 'CSS', 'JavaScript'];
for (const skill of skills) {
  console.log(skill);
}

// while loop
let count = 0;
while (count < 3) {
  console.log(count);
  count++;
}
```

## String Methods

```js filename="script.js"
const name = '  Yan Naing Htwe  ';

name.trim()          // 'Yan Naing Htwe'
name.toUpperCase()   // '  YAN NAING HTWE  '
name.toLowerCase()   // '  yan naing htwe  '
name.includes('Yan') // true
name.replace('Yan', 'YNH')  // '  YNH Naing Htwe  '
name.split(' ')      // ['', '', 'Yan', 'Naing', 'Htwe', '', '']

const email = 'user@example.com';
email.split('@')     // ['user', 'example.com']
```

## Console Methods

```js filename="script.js"
console.log('Regular message');
console.warn('Warning!');
console.error('Something went wrong');
console.table([{ name: 'Yan', age: 25 }]);
console.group('Group');
console.log('Inside group');
console.groupEnd();
```
