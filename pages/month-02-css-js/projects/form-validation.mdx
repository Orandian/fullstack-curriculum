# Project 2 — Form Validation

**Goal:** Build a registration form with full client-side JavaScript validation — no libraries.

## Requirements

- [ ] Fields: Name, Email, Password, Confirm Password
- [ ] Validate on submit AND on blur (when user leaves a field)
- [ ] Show error messages below each field
- [ ] Disable submit while fields are invalid
- [ ] Show success state after valid submission

## Evaluation Rubric

| Criteria | Points |
|---|---|
| All fields validate correctly | 30 |
| Error messages display properly | 20 |
| Password strength indicator | 20 |
| Success state shown after submit | 15 |
| Code is clean and readable | 15 |
| **Total** | **100** |
