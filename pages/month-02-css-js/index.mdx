# 🟢 Month 2 — CSS + JS Intro

**Goal:** Master CSS Grid and write your first JavaScript that interacts with a webpage.

<Callout type="info">
  This month you learn two big things: CSS Grid for layouts, and JavaScript basics for making pages interactive.
</Callout>

## Topics

| Lesson | Topic |
|---|---|
| 1 | Advanced CSS — CSS Grid, responsive layouts |
| 2 | JavaScript Basics — variables, functions, data types |
| 3 | DOM Manipulation — selecting elements, changing content |

## Projects

- **Landing Page with JS Interaction** — add animations and interactive elements
- **Form Validation** — validate a form with pure JavaScript
