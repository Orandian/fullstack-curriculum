# 🟢 Month 2 — CSS Grid, Tailwind + JS Intro

**Goal:** Master grid-based layouts, learn Tailwind CSS (used by the majority of modern React jobs), and write your first JavaScript that makes a page interactive.

<Callout type="info">
  Tailwind is not a shortcut — it's an industry standard. Learning it here means you'll be ready to work in any modern React codebase from Month 5 onwards.
</Callout>

## Topics This Month

| Lesson | Topic |
|--------|-------|
| 1 | CSS Grid — rows, columns, template areas, real layouts |
| 2 | Tailwind CSS — utility classes, responsive prefixes, dark mode |
| 3 | JavaScript Basics — variables, functions, data types, conditionals |
| 4 | DOM Manipulation — `querySelector`, events, `innerHTML`, forms |

## Projects

- **Landing Page (Tailwind)** — rebuild or redesign a landing page using Tailwind CSS utility classes
- **Form Validation** — validate a form with pure JavaScript: required fields, email format, password strength

## Weekly Schedule

<Steps>
  ### Week 1
  CSS Grid — `grid-template-columns`, `grid-template-areas`, `gap`, `auto-fill`. Build a card grid layout.

  ### Week 2
  Tailwind CSS — install and configure, utility class system, responsive prefixes (`sm:`, `md:`, `lg:`), hover states, dark mode. Rebuild your Month 1 profile page with Tailwind instead of raw CSS — you'll feel the difference immediately.

  ### Week 3
  JavaScript Basics — `let`/`const`, functions, strings, numbers, booleans, `if`/`else`, loops. Write your first scripts that run in the browser.

  ### Week 4
  DOM Manipulation — `querySelector`, `addEventListener`, `innerHTML`, form events. Build the form validation project and submit.
</Steps>

<Callout type="info">
  After this month you'll know both raw CSS and Tailwind. In real projects you'll reach for Tailwind — but knowing what's underneath makes you a much better developer.
</Callout>
