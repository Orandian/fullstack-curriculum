# 🔵 Month 5 — React Basics

**Goal:** Understand what React is, why it exists, and build your first component-based apps.

<Callout type="info">
  React is a JavaScript library for building UIs. Its key idea: describe **what** the UI should look like given some state, and React figures out **how** to update the DOM.
</Callout>

## Topics

| Lesson | Topic |
|---|---|
| 1 | Components & Props — the building blocks of React |
| 2 | State & useState — making components dynamic |
| 3 | useEffect — side effects and lifecycle |

## Projects

## Setup: Create Your First React App

```bash
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev
```
