# プロジェクト：カウンターアプリ集

## 概要

useStateの様々なユースケースを示す4つのミニアプリを作成してください。

## アプリ1：基本カウンター
- [ ] インクリメント・デクリメント・リセットボタン
- [ ] カウントが0のとき別の色で表示

## アプリ2：ライトスイッチ
- [ ] オン/オフ切り替え
- [ ] 状態に応じてスタイル変更

## アプリ3：文字カウンター
- [ ] テキストエリアの文字数をリアルタイム表示
- [ ] 制限（例：280文字）に近づくと警告色に変化

## アプリ4：ショッピングカート
- [ ] 商品リストから追加
- [ ] 数量変更・削除
- [ ] 合計金額の表示
