# 🔵 Month 5 — React 基礎

**目標：** Reactのコアコンセプト（コンポーネント・Props・State・副作用）を習得する。

<Callout type="info">
  ReactはUIを構築するためのJavaScriptライブラリです。Month 1〜4でHTMLとJavaScriptの基礎を学んだことで、ReactはそのJavaScriptを整理する方法として理解できます。
</Callout>

## 今月のトピック

| レッスン | 内容 |
|---------|------|
| 1 | コンポーネントとProps — UIを再利用可能なパーツに分割する |
| 2 | StateとuseState — コンポーネント内の変更可能なデータ |
| 3 | useEffect — データ取得・タイマー・副作用の処理 |

## プロジェクト

- **カウンターアプリ集** — useStateの様々なユースケースを実践
- **React Todo** — コンポーネントに分割したTodoアプリ

## 週次スケジュール

<Steps>
  ### 1週目
  Reactとは何か、なぜ使うのか。`create-next-app`のセットアップ。JSX構文。最初のコンポーネントを作成。

  ### 2週目
  Props — コンポーネントへのデータ渡し。useState — 状態とUI更新のサイクル。

  ### 3週目
  リストの表示（`map`）、条件付きレンダリング（`&&`、三項演算子）。

  ### 4週目
  useEffect — データ取得、クリーンアップ、依存配列。React TodoアプリとAPIからのデータ表示。
</Steps>
