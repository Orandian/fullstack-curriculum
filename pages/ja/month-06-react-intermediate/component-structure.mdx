# コンポーネント設計

良いコンポーネント設計はReactアプリを**保守しやすく、テストしやすく、拡張しやすく**します。

## いつコンポーネントを分割するか

```
コンポーネントを分割するタイミング：
1. 同じUIが複数の場所で使われる（再利用性）
2. コンポーネントが複雑になりすぎた（100行以上）
3. 論理的に独立した単位になる
4. 独立してテストしたい
```

## Presentational vs Container

```tsx
// Presentational（表示のみ）— データの取得をしない
function UserCard({ user, onDelete }: {
  user: User
  onDelete: (id: number) => void
}) {
  return (
    <div className="card">
      <h2>{user.name}</h2>
      <p>{user.email}</p>
      <button onClick={() => onDelete(user.id)}>削除</button>
    </div>
  )
}

// Container（ロジックを持つ）— データを取得してPresentationalに渡す
function UserListContainer() {
  const [users, setUsers] = useState<User[]>([])

  useEffect(() => {
    fetchUsers().then(setUsers)
  }, [])

  const handleDelete = async (id: number) => {
    await deleteUser(id)
    setUsers(users.filter(u => u.id !== id))
  }

  return (
    <div>
      {users.map(user => (
        <UserCard key={user.id} user={user} onDelete={handleDelete} />
      ))}
    </div>
  )
}
```

## 演習

1. 大きなコンポーネントを小さなコンポーネントに分割する
2. Propsのインターフェースを設計する
3. カスタムフック`useUsers()`を作ってロジックを分離する
