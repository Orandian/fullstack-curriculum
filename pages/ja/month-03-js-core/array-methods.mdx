# map・filter・reduce

これらは配列を操作する最も重要なメソッドです。Reactのどこでも使います。

<Callout type="info">
  これらのメソッドは元の配列を変更しません。常に新しい配列（または値）を返します。これを「イミュータブル」と呼びます。
</Callout>

## map — 変換

配列のすべての要素を変換した新しい配列を返します。

```js
const numbers = [1, 2, 3, 4, 5]

// 各要素を2倍にする
const doubled = numbers.map(n => n * 2)
// [2, 4, 6, 8, 10]

// オブジェクトの配列から特定のプロパティを取得
const users = [
  { name: "田中", age: 25 },
  { name: "鈴木", age: 30 },
]
const names = users.map(user => user.name)
// ["田中", "鈴木"]

// Reactでのリスト表示
const items = products.map(p => (
  <li key={p.id}>{p.name} — ¥{p.price}</li>
))
```

## filter — 絞り込み

条件に一致する要素だけを含む新しい配列を返します。

```js
const numbers = [1, 2, 3, 4, 5, 6]

// 偶数だけを取得
const evens = numbers.filter(n => n % 2 === 0)
// [2, 4, 6]

// アクティブなユーザーだけを取得
const activeUsers = users.filter(user => user.isActive)

// 価格でフィルタリング
const affordable = products.filter(p => p.price < 1000)
```

## reduce — 集約

配列を1つの値に集約します。

```js
const numbers = [1, 2, 3, 4, 5]

// 合計
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 15

// 最大値
const max = numbers.reduce((acc, n) => Math.max(acc, n), -Infinity)
// 5

// オブジェクトの配列の合計
const totalPrice = cart.reduce((acc, item) => acc + item.price, 0)
```

## メソッドのチェーン

```js
const result = products
  .filter(p => p.inStock)           // 在庫ありのみ
  .map(p => ({ ...p, price: p.price * 0.9 }))  // 10%割引
  .sort((a, b) => a.price - b.price) // 価格順

// アクティブなユーザーの名前リスト
const activeNames = users
  .filter(u => u.isActive)
  .map(u => u.name)
```

## その他のよく使うメソッド

```js
// find — 最初に一致した要素を返す
const user = users.find(u => u.id === 5)

// some — 条件に一致する要素が1つでもあればtrue
const hasAdmin = users.some(u => u.role === "admin")

// every — すべての要素が条件に一致すればtrue
const allActive = users.every(u => u.isActive)

// flat — ネストした配列を平坦化
const nested = [[1, 2], [3, 4], [5]]
nested.flat() // [1, 2, 3, 4, 5]
```
