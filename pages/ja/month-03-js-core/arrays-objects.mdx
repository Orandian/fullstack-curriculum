# 配列とオブジェクト

配列とオブジェクトはJavaScriptで最も重要なデータ構造です。React・Node・TypeScriptのどこでも使います。

## 配列

```js
// 作成
const colors = ["赤", "青", "緑"]

// 読み取り
colors[0]           // "赤"（インデックスは0から始まる）
colors.length       // 3

// 基本メソッド
colors.push("黄")   // 末尾に追加
colors.pop()        // 末尾を削除して返す
colors.unshift("白") // 先頭に追加
colors.shift()      // 先頭を削除して返す

// スライス（元の配列を変更しない）
colors.slice(1, 3)  // ["青", "緑"]

// 検索
colors.includes("赤")     // true
colors.indexOf("青")      // 1
colors.find(c => c === "緑") // "緑"
```

## 分割代入

```js
const [first, second, ...rest] = ["a", "b", "c", "d"]
// first = "a", second = "b", rest = ["c", "d"]

// 値のスワップ
let a = 1, b = 2
;[a, b] = [b, a]
// a = 2, b = 1
```

## スプレッド演算子

```js
const arr1 = [1, 2, 3]
const arr2 = [4, 5, 6]

// 配列のコピー（参照ではなく新しい配列）
const copy = [...arr1]

// 配列の結合
const combined = [...arr1, ...arr2]

// 関数への展開
Math.max(...arr1) // 3
```

## オブジェクト

```js
// 作成
const user = {
  name: "田中太郎",
  age: 25,
  isActive: true,
  address: {
    city: "東京",
    country: "日本",
  }
}

// 読み取り
user.name           // "田中太郎"
user["age"]         // 25（動的なキーに便利）
user.address.city   // "東京"
```

## オブジェクトの分割代入

```js
const { name, age, isActive } = user
// name = "田中太郎", age = 25

// 別名をつける
const { name: userName } = user
// userName = "田中太郎"

// デフォルト値
const { role = "ユーザー" } = user
// role = "ユーザー"（userにroleがないため）

// ネストしたオブジェクト
const { address: { city } } = user
// city = "東京"
```

## オブジェクトのスプレッド

```js
const baseUser = { name: "花子", role: "user" }

// コピーして上書き
const admin = { ...baseUser, role: "admin" }
// { name: "花子", role: "admin" }

// オブジェクトの更新（イミュータブルパターン）
const updatedUser = { ...user, age: 26 }
```

<Callout type="warning">
  配列やオブジェクトを**直接変更（ミューテート）しない**ことが重要です。代わりに`[...arr]`や`{...obj}`で新しいコピーを作りましょう。これはReactで特に重要です。
</Callout>
