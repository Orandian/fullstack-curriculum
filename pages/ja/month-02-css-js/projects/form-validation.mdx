# プロジェクト：フォームバリデーション

## 概要

クライアントサイドのバリデーションを実装した登録フォームを作成してください。

## 要件

- [ ] 名前、メールアドレス、パスワード、パスワード確認のフィールド
- [ ] 各フィールドのリアルタイムバリデーション（入力中またはフォーカスが外れたとき）
- [ ] エラーメッセージの表示（フィールドの下に赤いテキスト）
- [ ] すべて有効な場合のみ送信ボタンが有効になる
- [ ] パスワードの表示/非表示トグル
- [ ] 送信成功時のメッセージ表示
- [ ] Tailwindでスタイリング
