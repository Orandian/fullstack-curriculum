# プロジェクト：JavaScriptランディングページ

## 概要

Tailwind CSSでスタイリングし、JavaScriptでインタラクションを追加したランディングページを作成してください。

## 要件

- [ ] Tailwind CSSを使ったスタイリング（カスタムCSSは最小限）
- [ ] モバイルハンバーガーメニュー（クリックで開閉）
- [ ] スムーズスクロールナビゲーション
- [ ] 少なくとも1つのインタラクティブ要素（モーダル、タブ、アコーディオンなど）
- [ ] ダーク/ライトモード切り替えボタン
- [ ] レスポンシブデザイン
- [ ] GitHubにプッシュ + GitHub Pagesでデプロイ
