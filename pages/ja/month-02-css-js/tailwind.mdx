# Tailwind CSS

Tailwindは**ユーティリティファースト**のCSSフレームワークです。事前定義されたクラスをHTMLに直接適用してスタイリングします。

<Callout type="info">
  Tailwindを使うとCSSファイルをほとんど書かなくなります。すべてのスタイルはHTMLクラスとして適用します。最初は奇妙に感じますが、慣れると非常に速くなります。
</Callout>

## インストール

```bash
npm install -D tailwindcss
npx tailwindcss init
```

```js
// tailwind.config.js
export default {
  content: ["./src/**/*.{html,js}"],
  theme: { extend: {} },
  plugins: [],
}
```

```css
/* input.css */
@tailwind base;
@tailwind components;
@tailwind utilities;
```

## 基本的なクラス

```html
<!-- テキスト -->
<p class="text-lg font-bold text-gray-800">テキスト</p>
<h1 class="text-4xl font-black tracking-tight">見出し</h1>

<!-- スペーシング -->
<div class="p-4 m-2">          <!-- padding: 1rem, margin: 0.5rem -->
<div class="px-6 py-3">        <!-- 左右padding: 1.5rem, 上下: 0.75rem -->
<div class="mt-8 mb-4">        <!-- 上margin: 2rem, 下: 1rem -->

<!-- 色 -->
<div class="bg-blue-500 text-white">
<div class="border border-gray-200 rounded-lg">

<!-- Flexbox -->
<div class="flex items-center justify-between gap-4">

<!-- レスポンシブ -->
<div class="flex-col md:flex-row">
```

## レスポンシブプレフィックス

```html
<!-- モバイル: 縦積み | タブレット以上: 横並び -->
<div class="flex flex-col md:flex-row gap-4">
  <div class="w-full md:w-1/3">サイドバー</div>
  <div class="w-full md:w-2/3">メインコンテンツ</div>
</div>

<!-- テキストサイズのレスポンシブ対応 -->
<h1 class="text-2xl md:text-4xl lg:text-6xl font-bold">
  ヒーローテキスト
</h1>
```

## ボタンの例

```html
<button class="
  bg-cyan-400 hover:bg-cyan-300
  text-black font-bold
  px-6 py-3 rounded-md
  transition-colors duration-200
  focus:outline-none focus:ring-2 focus:ring-cyan-500
">
  今すぐ始める
</button>
```
