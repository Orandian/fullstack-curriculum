# 🟢 Month 2 — CSS Grid・Tailwind + JS入門

**目標：** レイアウトの完成度を高め、JavaScriptの基礎を習得してページをインタラクティブにする。

<Callout type="info">
  Month 2の前半はCSSをさらに深掘りします。後半からJavaScriptを始めます。Month 1でHTMLとCSSに自信がついた状態で臨んでください。
</Callout>

## 今月のトピック

| レッスン | 内容 |
|---------|------|
| 1 | CSS Grid — 2次元レイアウト、テンプレートエリア |
| 2 | Tailwind CSS — ユーティリティファーストのスタイリング |
| 3 | JavaScript基礎 — 変数、データ型、関数、条件分岐 |
| 4 | DOM操作 — 要素の取得と変更、イベントリスナー |

## プロジェクト

- **JavaScriptランディングページ** — Tailwindでスタイリング、JSでインタラクション追加
- **フォームバリデーション** — クライアントサイドバリデーション付きのフォーム

## 週次スケジュール

<Steps>
  ### 1週目
  CSS Grid — `grid-template-columns`、`grid-template-areas`、`gap`。ギャラリーレイアウトとダッシュボードグリッドを作成。

  ### 2週目
  Tailwind CSS — インストール、ユーティリティクラス、レスポンシブプレフィックス（`sm:`、`md:`、`lg:`）。Tailwindを使ってMonth 1のプロジェクトをリビルド。

  ### 3週目
  JavaScript基礎 — `let`/`const`、文字列/数値/真偽値、`if`/`else`、関数（`function`と`=>`）、`for`ループ。

  ### 4週目
  DOM操作 — `document.querySelector`、`.textContent`、`.classList`、`addEventListener`。クリックで変化するページを作成。
</Steps>
