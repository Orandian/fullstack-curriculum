# プロジェクト：CRUD API

## 概要

PostgreSQL + Prisma + Docker Composeを使ったCRUD APIを作成してください。

## 要件

- [ ] PostgreSQL + PrismaでDB設計
- [ ] 少なくとも3つのモデルとリレーション
- [ ] 全エンドポイントのCRUD実装
- [ ] 入力バリデーション（Zod推奨）
- [ ] エラーハンドリング
- [ ] docker-compose.ymlで一発起動
- [ ] Postmanコレクションまたはswagger
