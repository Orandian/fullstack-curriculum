# 🔵 Month 7 — TypeScript + React

**目標：** TypeScriptを習得し、型安全なReactアプリを書けるようになる。

<Callout type="info">
  TypeScriptはJavaScriptに型チェックを追加したものです。コードのバグを書く前に見つけられます。現代のReact開発の標準です。
</Callout>
