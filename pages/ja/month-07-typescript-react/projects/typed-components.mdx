# プロジェクト：型付きコンポーネント

## 概要

TypeScriptで書かれた再利用可能なコンポーネントライブラリを作成してください。

## コンポーネント一覧

- [ ] `Button` — variant・size・disabled Props
- [ ] `Badge` — label・color Props
- [ ] `Modal` — isOpen・onClose・children Props
- [ ] `DataTable<T>` — columns・data・onRowClick Props（ジェネリクス必須）
- [ ] `Pagination` — currentPage・totalPages・onChange Props
