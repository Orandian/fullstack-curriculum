# プロジェクト：認証UI

## 概要

Context APIとReact RouterとTypeScriptを使った完全な認証フローを実装してください。

## 要件

- [ ] ログインページ（バリデーション付き）
- [ ] 登録ページ
- [ ] AuthContext（ユーザー状態・ログイン・ログアウト）
- [ ] 保護されたルート（未ログインはログインにリダイレクト）
- [ ] JWT tokenのlocalStorageへの保存
- [ ] ページリロード後も認証状態が維持される
- [ ] 完全なTypeScript型付け
