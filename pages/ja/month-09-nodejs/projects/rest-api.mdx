# プロジェクト：REST API

## 概要

Express + TypeScript + Dockerを使ったCRUD REST APIを作成してください。

## 要件

- [ ] Express + TypeScriptで構築
- [ ] 少なくとも2つのリソース（例：users・posts）のCRUD
- [ ] リクエストバリデーション
- [ ] エラーハンドリングミドルウェア
- [ ] ルーターでファイルを分割
- [ ] Dockerfileでコンテナ化
- [ ] Docker Composeでapi + dbを一緒に起動
- [ ] Postmanでのエンドポイントテスト
- [ ] `/health`エンドポイント
