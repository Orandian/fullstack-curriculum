# 🟢 Month 1 — HTML + CSS

**目標：** ウェブページの見た目と構造を作る基礎スキルを習得する。

<Callout type="info">
  Month 1はプログラミング経験ゼロの状態から始まります。すでにHTMLとCSSの基礎を知っている場合は、レスポンシブデザインとFlexboxのレッスンに集中してください。
</Callout>

## 今月のトピック

| レッスン | 内容 |
|---------|------|
| 1 | HTML構造 — セマンティックタグ、ドキュメント構造 |
| 2 | CSS基礎 — セレクタ、ボックスモデル、基本スタイリング |
| 3 | Flexbox — 1次元レイアウト、ナビゲーション、カードグリッド |
| 4 | レスポンシブデザイン — メディアクエリ、モバイルファースト |

## プロジェクト

- **ランディングページ** — ナビゲーション、ヒーロー、フィーチャーセクション、フッターを含む完全なページ
- **プロフィールページ** — あなた自身についてのシンプルな紹介ページ（実際のポートフォリオとして使える）

## 週次スケジュール

<Steps>
  ### 1週目
  HTML構造 — `<header>`、`<main>`、`<section>`、`<article>`、`<footer>`などのセマンティックタグ。属性、リンク、画像、フォームの基礎。

  ### 2週目
  CSS基礎 — セレクタ、ボックスモデル（margin/padding/border）、テキストスタイリング、色。シンプルな静的ページをスタイリングする。

  ### 3週目
  Flexbox — コンテナとアイテムのプロパティ、justify-content、align-items、ギャップ。ナビゲーションバーとカードグリッドを作成。

  ### 4週目
  レスポンシブデザイン — メディアクエリ、モバイルファーストアプローチ。ランディングページをすべての画面サイズで動作するように仕上げる。
</Steps>
