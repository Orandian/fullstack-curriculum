# プロジェクト：ランディングページ

## 概要

架空のプロダクトまたはサービスのための、完全なレスポンシブランディングページを作成してください。

## 要件

- [ ] ナビゲーションバー（ロゴ + リンク）
- [ ] ヒーローセクション（見出し、サブテキスト、CTAボタン）
- [ ] フィーチャーセクション（少なくとも3つのフィーチャーカード）
- [ ] フッター（リンク + コピーライト）
- [ ] モバイルレスポンシブ（768px未満で縦積みレイアウト）
- [ ] Flexboxを使ったレイアウト（Gridは使わない）
- [ ] コードをGitHubリポジトリにプッシュする
- [ ] GitHub Pagesでデプロイする

## 提出方法

GitHub リポジトリのURLとデプロイしたURLを提出してください。
