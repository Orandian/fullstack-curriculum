# プロジェクト：プロフィールページ

## 概要

自分自身のプロフィールページを作成してください。これはポートフォリオの最初のページになります。

## 要件

- [ ] プロフィール写真または画像プレースホルダー
- [ ] 自己紹介文（2〜3段落）
- [ ] スキルリスト（現時点のもので構わない）
- [ ] GitHubへのリンク
- [ ] 連絡先情報またはお問い合わせセクション
- [ ] モバイルレスポンシブ
- [ ] GitHub Pagesでデプロイ

## ヒント

完璧である必要はありません。このプログラムを進めるにつれて更新していきます。今はHTMLとCSSをできる限り使ってください。
