# 🟠 Month 11 — フルスタックプロジェクト

**目標：** React フロントエンド + Node.js/Express バックエンド + PostgreSQL データベースを1つの実際にデプロイできるアプリに統合する。

<Callout type="info">
  Month 11は**3つの設計レッスン**から始まります。コードを書く前にアプリを計画・設計する方法を学びます。このステップを飛ばすとプロジェクトは途中で崩壊します。レッスンは短く、得られるものは大きいです。
</Callout>

## 技術スタック

```
フロントエンド:  Next.js 14 + TypeScript + Tailwind CSS
バックエンド:   Node.js + Express + Prisma
データベース:   PostgreSQL
認証:          JWT + bcrypt
インフラ:      Docker Compose
デプロイ:      Vercel（フロントエンド）+ Render（バックエンド）
```

<Callout type="warning">
  **なぜNext.jsを使うのか？** Reactを使うほとんどの企業でNext.jsが使われています。Month 11が導入のタイミングです — Reactの知識がほぼそのまま使えます。詳しくはレッスン4を見てください。
</Callout>

## Month構成

| 週 | 内容 |
|---|------|
| 1週目 | レッスン1〜3：アプリを計画し、スキーマを設計し、API契約を書く |
| 2週目 | レッスン4（Next.js）+ フロントエンド・バックエンドのスキャフォールド |
| 3〜4週目 | コア機能を構築 — 認証・主要CRUD・基本UI |
| 5週目 | 仕上げ・バグ修正・デプロイ・README作成 |

## チームプロジェクト

2〜3人のグループで作業します。役割を決めてください：フロントエンド、バックエンド、DB/API設計。GitHubブランチとプルリクエストを使うこと — 義務だからではなく、これが実際のチームがソフトウェアを出荷する方法だからです。

## プロジェクト要件（すべての選択肢共通）

- [ ] ユーザー登録 + ログイン（JWT）
- [ ] フロントエンドとバックエンド両方の保護されたルート
- [ ] 少なくとも3つのDBモデルとリレーション
- [ ] メインリソースの完全なCRUD
- [ ] レスポンシブUI（Tailwindでモバイル+デスクトップ対応）
- [ ] デプロイ済みで公開URLからアクセス可能
- [ ] セットアップ手順とスクリーンショット付きREADME
- [ ] フィーチャーブランチ + マージ済みPRのGitHubワークフロー
