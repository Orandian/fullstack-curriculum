# プロジェクト：GitHub APIビューア

## 概要

GitHub REST APIを使って、ユーザー情報とリポジトリ一覧を表示するアプリを作成してください。

## 要件

- [ ] ユーザー名の検索フォーム
- [ ] プロフィール情報の表示（アバター、名前、フォロワー数）
- [ ] リポジトリ一覧（スター数・言語・説明付き）
- [ ] スター数でのソート
- [ ] ローディング・エラー状態のUI
- [ ] GitHubのAPIを使用（認証不要）

## APIエンドポイント

- ユーザー情報：`https://api.github.com/users/{username}`
- リポジトリ：`https://api.github.com/users/{username}/repos`
