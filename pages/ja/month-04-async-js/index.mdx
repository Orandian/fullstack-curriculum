# 🟡 Month 4 — 非同期 JavaScript

**目標：** 非同期プログラミングを習得し、外部APIとデータのやり取りができるようになる。

<Callout type="info">
  Month 4はJavaScriptの仕上げです。非同期処理とAPIはReact・Node・すべての現代的なウェブ開発の中心です。これを理解しないとReactで詰まります。
</Callout>

## 今月のトピック

| レッスン | 内容 |
|---------|------|
| 1 | Promise・async/await — 非同期コードの書き方 |
| 2 | Fetch API・エラーハンドリング — 外部APIとの通信 |

## プロジェクト

- **天気アプリ** — OpenWeatherMap APIを使ったリアルタイム天気表示
- **GitHub APIビューア** — GitHub APIでユーザー情報を取得して表示

## 週次スケジュール

<Steps>

  ### 3週目
  天気アプリの作成 — APIキーの管理、ローディング状態、エラー状態のUI。

  ### 4週目
  GitHub APIビューアの完成 + Month 4の総復習。
</Steps>
